01. Generate exactly one horizontal desktop product-UI image.
02. This single image is one focused screen, not a collage.
03. Target dimensions are 1440 x 1024.
04. The image is an art-direction anchor for a React prototype.
05. The implementation will cover Lab, Projects, Study, and Runs later.
06. This image should focus on the Lab Home during a stub Run.
07. Do not draw multiple pages inside the frame.
08. Do not create a long scrolling page.
09. Do not include browser chrome or a device bezel.
10. All visible copy should be concise pt-BR.

## Product

15. Scenario: `deployment-log-trace`.

## Design thesis

21. Direction name: `Carbon Rhythm`.
22. Imagine an executive audio console crossed with a precision run monitor.
23. The interface is dark, quiet, expensive, and technically credible.
24. It must not look cyberpunk.
25. It must not look like a generic observability dashboard.
26. It must not look like ChatGPT.
27. Use deep carbon and graphite as the primary field.
28. Use warm off-white for text and key surfaces.
29. Use one restrained oxidized-orange accent.
30. Use silver-gray for secondary structure.
31. No purple or blue glow.
32. No green database icon.
33. No rainbow status palette.
34. Success relies on check shape, label, and contrast.
35. Error may use the same orange at higher emphasis plus an X.

## Typography and spacing

36. Use a refined neo-grotesk sans.
37. IDs may use a compact mono.
38. Body copy must read at 15-16px equivalent.
39. Avoid tiny decorative labels.
40. Avoid all-caps everywhere.
41. Use strong but not oversized headings.
42. Keep line lengths comfortable.
43. Use generous negative space around the primary task.
44. Keep dense operational details grouped, not scattered.
45. Avoid long columns of hairline-separated rows.
46. Avoid narrow text panes.
47. Avoid full-width button slabs.
48. Buttons are compact and content-sized.
49. Use one consistent radius system around 10-12px.
50. Shadows are nearly absent; depth comes from tonal fields.

## Shell

51. Use a compact horizontal command rail at the top.
52. Include product mark and `EvidRun` at top left.
53. Include four destinations: Lab, Projects, Study, Runs.
54. Lab is active.
55. Include a compact Project switcher near the navigation.
56. Do not use a wide persistent ChatGPT-like sidebar.

82. The spinner should resemble three resolving timing marks or a rotating trace.
83. It must not be a generic circular border spinner.

87. Show a collapsible block titled `Atividade observável`.

## Icon discipline

116. One icon family only.
117. Modern outline icons with consistent 1.5-2px weight.
118. Project uses a folder/bounding-box icon.
