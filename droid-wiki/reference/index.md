# Reference

Lookup material for Evidrun: settings and environment variables, the persisted data models and generated contract schemas, and the external dependencies. These pages are tables you scan, not narratives you read start to finish.

## Pages

- [Configuration](configuration.md) — the `Settings` object, the default provider profile, and every environment variable with its default and effect.
- [Data models](data-models.md) — the SQLAlchemy tables in the local SQLite store, plus an index of the generated JSON Schema contracts.
- [Dependencies](dependencies.md) — the Python and Node dependencies, why each is used, and the local CLIProxyAPI provider dependency.
