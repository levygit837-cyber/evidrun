# Métricas de sucesso

O Evidrun deve reduzir o tempo entre hipótese e evidência sem diminuir a qualidade experimental.

Métricas candidatas:

- proporção de comparações com variável primária explícita;
- proporção de conclusões com evidência navegável;
- taxa de bundles verificáveis;
- tempo para reproduzir um experimento;
- taxa de runs recuperadas após falha;
- frequência de conclusões rebaixadas corretamente para `exploratory`;
- consistência de resultados em repetições;
- quantidade de raw sensível retido além do TTL sem justificativa — alvo zero.

Targets numéricos serão aceitos após uso interno suficiente para estabelecer baseline.
