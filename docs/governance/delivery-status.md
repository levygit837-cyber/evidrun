# Estados de entrega

`draft → proposed → accepted → implemented → verified`.

- Accepted: decisão aprovada.
- Implemented: comportamento existe e possui referências.
- Verified: evidência executável confirma o comportamento.
- Deprecated: ainda existe, mas não deve receber novos consumidores.
- Superseded: existe apenas como histórico e aponta para sucessor.
- Rejected: proposta preservada com motivo de rejeição.

Não usar “pronto” para misturar essas etapas.
