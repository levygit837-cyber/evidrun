# Origem no Context Reliability Lab

O projeto deriva da tese de que “context engineering” precisa ser tratado como sistema observável e
avaliado, não como um conjunto de truques de prompt. As notas originais continuam no Obsidian como
histórico de pesquisa. Este repositório passa a ser a fonte normativa para decisões e contratos.

Conceitos promovidos: benchmark-first, local-first, run auditável, variável primária, modos de
evidência, graders determinísticos e perdas visíveis.
